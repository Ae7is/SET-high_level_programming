# python-everything_is_object

Questions and exercises about Python objects: identity, mutability, integers,
strings, tuples and lists.

- `0-answer.txt` to `28-answer.txt`: short answers about `id`, `type`, `is`,
  `==`, mutable and immutable objects
- `19-copy_list.py`: returns a copy of a list
- `100-magic_string.py`: returns "BestSchool" repeated one more time on each call
- `101-locked_class.py`: a class that only accepts the attribute `first_name`
- `103-*.txt` to `106-*.txt`: how CPython creates and reuses int and string objects
