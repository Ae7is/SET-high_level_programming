# python-classes

Python classes: private attributes, properties, validation, special methods
and a sorted linked list.

| File | Description |
|---|---|
| `0-square.py` | An empty `Square` class |
| `1-square.py` | `Square` with a private size |
| `2-square.py` | Size validation with `TypeError` and `ValueError` |
| `3-square.py` | Adds `area()` |
| `4-square.py` | Size getter and setter (property) |
| `5-square.py` | Adds `my_print()` |
| `6-square.py` | Adds a validated `position` |
| `100-singly_linked_list.py` | `Node` and `SinglyLinkedList` with `sorted_insert` |
| `101-square.py` | Printing a `Square` instance behaves like `my_print()` |
| `102-square.py` | Squares compared by area with `==`, `!=`, `<`, `<=`, `>`, `>=` |
| `103-magic_class.py` | `MagicClass`, rewritten from Python bytecode |
