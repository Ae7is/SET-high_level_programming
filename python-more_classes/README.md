# python-more_classes

Python classes: properties, special methods, class attributes, static and
class methods, plus the N queens puzzle.

| File | Description |
|---|---|
| `0-rectangle.py` | An empty `Rectangle` class |
| `1-rectangle.py` | Validated `width` and `height` properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | `str()` draws the rectangle with `#` |
| `4-rectangle.py` | `repr()` can be used with `eval()` to recreate it |
| `5-rectangle.py` | Prints `Bye rectangle...` when deleted |
| `6-rectangle.py` | `number_of_instances` class attribute |
| `7-rectangle.py` | `print_symbol` class attribute |
| `8-rectangle.py` | Static method `bigger_or_equal` |
| `9-rectangle.py` | Class method `square` |
| `101-nqueens.py` | Prints every solution of the N queens puzzle |
