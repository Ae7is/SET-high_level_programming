# python-input_output

Reading and writing files, JSON serialization and a few small utilities.

| File | Description |
|---|---|
| `0-read_file.py` | Reads a UTF8 text file and prints it |
| `1-write_file.py` | Writes a string to a file and returns the character count |
| `2-append_write.py` | Appends a string to a file |
| `3-to_json_string.py` | Object to JSON string |
| `4-from_json_string.py` | JSON string to object |
| `5-save_to_json_file.py` | Saves an object to a file as JSON |
| `6-load_from_json_file.py` | Loads an object from a JSON file |
| `7-add_item.py` | Adds the arguments to a list stored in `add_item.json` |
| `8-class_to_json.py` | Dictionary description of an object |
| `9-student.py` | `Student` with `to_json()` |
| `10-student.py` | `to_json()` with an attribute filter |
| `11-student.py` | Adds `reload_from_json()` |
| `12-pascal_triangle.py` | Pascal's triangle of n |
| `100-append_after.py` | Inserts a line after each line containing a string |
| `101-stats.py` | Computes file size and status code metrics from stdin |
