# python-network_1

Python scripts that make HTTP requests, using `urllib` and `requests`.

- `0-hbtn_status.py` to `3-error_code.py`: fetch pages, read headers, send a
  POST and handle HTTP errors with `urllib`
- `4-hbtn_status.py` to `8-json_api.py`: the same tasks plus a JSON search API,
  with `requests`
- `10-my_github.py`: display a GitHub user id with Basic Authentication
- `100-github_commits.py`: list the 10 latest commits of a repository
